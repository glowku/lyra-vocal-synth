# Lyra

**Physical-modeling musical TTS & vocal synthesizer**

> Every sound is generated by simulating air flowing through a digital airway (lungs → vocal folds / syrinx → branched vocal tract → lips & nose).  
> No samples. No concatenative stitching. Pure physics.

## How to test / use from GitHub right now

### 1. Clone the repository

```bash
git clone https://github.com/glowku/lyra-vocal-synth.git
cd lyra-vocal-synth
```

### 2. Install Rust (if needed)

```bash
# https://rustup.rs
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env
rustup target add wasm32-unknown-unknown   # for later WASM builds
```

### 3. Build & run the CLI

```bash
# Check that the workspace compiles
cargo build --workspace

# Show info
cargo run -p lyra-cli -- info

# Render a vowel (currently writes a small stub WAV – real audio comes with FDTD)
cargo run -p lyra-cli -- render vowel a 220 --out a4.wav --body female
cargo run -p lyra-cli -- render vowel i 440 --out i5.wav --body male
```

### 4. Run tests

```bash
cargo test --workspace
```

### 5. Open the interactive preview page locally

```bash
# Just open the file in a browser
open docs/index.html          # macOS
xdg-open docs/index.html      # Linux
start docs/index.html         # Windows
```

Or serve it:

```bash
cd docs
python3 -m http.server 8080
# then open http://localhost:8080
```

### 6. Activate GitHub Pages (recommended)

1. Go to the repo → **Settings** → **Pages**
2. Source = **Deploy from a branch**
3. Branch = `main` / folder = `/docs`
4. Save → after ~1 min the demo is live at  
   `https://glowku.github.io/lyra-vocal-synth/`

## Design principles

1. **Physics first** — every sound must be explainable by the airway model.
2. **Deterministic & real-time safe** — the audio callback must stay allocation-free.
3. **Same engine everywhere** — browser, CLI and future plugins share the exact same Rust code.
4. **Beautiful by default** — the UI is part of the instrument.
5. **Honest progress** — this README always reflects the real current state.
